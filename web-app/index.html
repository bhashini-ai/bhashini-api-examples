Bhashini.ai API Example

Streaming speech-to-text in plain HTML + JavaScript

This sample shows how to capture microphone audio, stream raw PCM over WebSocket, and keep a text area updated with interim and final transcripts. It can also be re-used in any web-app based on Vue, React, Angular, or any other framework.

How to reuse this

  • Copy streaming-speech-client.js and pcm-capture.worklet.js into your project.
  • Create a StreamingSpeechClient instance with your API key, language, and callbacks.
  • Wire the client into your own UI components, forms, or state management.

This demo must be served from http:// or https:// so microphone access and AudioWorklet loading can work correctly. The API key field should contain only your 32-character Bhashini API key, not a server URL.
